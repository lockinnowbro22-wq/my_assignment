HTML Lists

Explanation

HTML listing is simply a way to organize items on a webpage so they are easy to read
like steps, bullet points, or definitions.

There are ordered lists, unordered lists, and definition lists.

Ordered List (Numbered List)
This is used when order matters
(steps, rankings, procedures).
Example:

  1. Wake up
  2. Brush teeth
  3. Go to school
Unordered List (Bullet List)
Used when order does not matter.
Example:
  • Rice
  • Beans
  • Yam
Definition List
Used for terms and meanings (like dictionary).
Example:
HTML
HyperText Markup Language
CSS
Used for styling web pages
